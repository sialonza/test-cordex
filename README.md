# スケジュール & To-Do プランナー

予定とタスクをまとめて管理できる、純粋な HTML/JavaScript のシングルページアプリです。ブラウザだけで動作し、入力はローカルストレージに保存されるため、リロード後も内容が残ります。

## 収録ファイル
- `index.html` : アプリ本体 (スタイルとスクリプトを 1 ファイルに同梱)

## 使い方
1. このリポジトリを clone または ZIP 展開します。
2. `index.html` をブラウザで開くだけで動作します (HTTP サーバーは不要)。
3. スケジュールまたは To-Do のフォームに入力し、**追加** ボタンで登録します。
4. 予定は日付/時間順に表示されます。タスクは優先度・期限を含めて表示され、チェックボックスで完了できます。
5. 完了したタスクは「完了タスクを削除」で一括クリアできます。

## 主な機能
- スケジュール管理 (日付/時間/場所/メモ付き)
- To-Do 管理 (優先度・期限・メモ付き、完了トグル、フィルター、完了タスク削除)
- サマリーカードで「次の予定」「未完了数」「完了率」を表示
- ローカルストレージへの自動保存 (ブラウザ内のみで完結)
